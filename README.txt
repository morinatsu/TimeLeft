=========================================
TimeLeft 拡張機能
=========================================

■ 概要
TimeLeftは、Microsoft Edge や Google Chrome で使えるシンプルなタイマー拡張機能です。
指定した時間（または時刻）に向けて、緑から赤へと色が変化するバーで視覚的に残り時間を教えてくれます。
時間が近づくと背景が点滅してお知らせします。
好きな場所に移動できる独立したミニウィンドウで開くので、作業のお供に最適です。

■ 使い方
1. ブラウザ右上の「TimeLeft」アイコンをクリックして起動します。
2. 入力欄に、分（例: 15）または、目標時刻（例: 14:30）を入力します。
3. 「Start」ボタンを押すとタイマーが開始します。
4. 途中でやり直したい場合や、タイマーが終わった後は「Reset」ボタンを押すと元に戻ります。

■ インストール手順
この拡張機能は、以下の手順に沿って手動でブラウザに読み込ませます。

1. もらったZIPファイルを、デスクトップなど、わかりやすい場所に解凍（展開）します。
   ※ 中にある「src」フォルダが本体です。このフォルダは今後も削除したり移動したりしないでください。

2. ブラウザ（Edge または Chrome）を開きます。
   - Edgeの場合: アドレスバー（URLを入れる場所）に「 edge://extensions/ 」と入力してEnter。
   - Chromeの場合: アドレスバーに「 chrome://extensions/ 」と入力してEnter。

3. 拡張機能の管理画面が開いたら、画面にある「開発者モード（またはデベロッパーモード）」というスイッチを探して「オン」にします。
   （Edgeの場合は画面左下、Chromeの場合は画面右上にあります）

4. 新しく現れる「パッケージ化されていない拡張機能を読み込む」というボタンをクリックします。

5. フォルダを選択する画面が出るので、手順1で解凍した中にある「src」フォルダを選択して、「フォルダーの選択」をクリックします。

6. 拡張機能の一覧に「TimeLeft」が追加されれば準備完了です！
   ※ ブラウザの右上にある「パズルピース」のアイコンをクリックして、TimeLeftの「目玉マーク」や「ピン留めマーク」を押して常に表示しておくと便利です。

■ ご注意
セキュリティの都合上、ブラウザを起動した際に「開発者モードの拡張機能を無効にしますか？」といった警告が出ることがあります。その場合は「キャンセル」や「そのままにする」を選んで無効化しないようにしてください。
